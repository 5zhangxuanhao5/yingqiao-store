# 映桥 0.4.0 单应用合并候选（build 41）

同一应用、同一窗口提供“平板扩展屏”和“Mac 互联”。平板使用原有发现、USB/LAN切换与采集核心，Mac互联沿用用户已验收的独立接收端。切换页签不结束会话；显式结束只影响对应会话；退出应用结束两类会话。

Mac互联可选择接收或发送。接收窗口采用实际屏幕像素，Air实测前身为2560×1664；合并版本身尚待设备验收。默认发送待命；Air 可使用 `open -a 映桥 --args --mac-receive` 直接进入接收页，也可在窗口内切换。两台Mac当前使用局域网，未实现Mac间线缆自动路由。

编译：`YQ_MAC_UNIFIED=1 YQ_ORIGINAL_USB_TEST=1 bash mac/build.sh`。原独立测试构建和普通构建仍保留，合并版不包含互联网远控。无需安装两个应用。

沿用公版bundle标识和本机配对存储，不复制私人令牌。旧独立接收测试的临时配对身份不迁移；新连接仍需发送端允许。临时签名更新后macOS可能要求重新登记录屏和键鼠授权。安装前须结束公版及独立测试会话；保留可回退副本。完整版不替换。

修复录屏拒绝后立即关闭连接导致错误提示丢失的问题；错误发送完成后再关闭，接收端显示失败原因。

验证：universal arm64/x86_64 构建、原扩展屏策略自检、Mac收屏协议/解密/尺寸自检。合并版四屏同时工作、Air交互、退出资源释放仍待实测，不能将独立测试的成功当作合并版验收。Edge后台/息屏保留尚未实现，不包含在此候选。

## 界面统一候选 test.2

Mac互联页直接复用原版 StoreDashboard/BridgeCard/BridgeTheme，保留原首页的品牌区、主操作卡、等高权限与附近设备卡。角色选择放在品牌副标题位置，两种连接模式共用同一套按钮与状态显示。不改Edge协议和设备分类。

## test.3 / build 42

去除页签外框及 Mac 权限和设备区域边框。缺少录屏权限时明确拒绝而非先弹连接确认。两端已安装并短暂收到 2560×1664 画面，随后用户反馈断连，发送端报告找不到可捕获屏幕；本版标记为未通过稳定性验收。未验证普通 USB-C 线可传屏，现场两端雷雳桥均未建立。

## test.4 / build 43

在 Mac 设备发现后以固定证书校验的加密探测检查实时可达性、发送端录屏与键鼠权限及空闲状态；未通过检查时连接按钮禁用，探测结果过期不再视为就绪。每 3 秒探测，2 秒超时，会话连接期间停止探测。离线自动禁用不能保证点击后网络永不变化。

为异步启动、停止失败回调加入会话代次与采集对象检查，防止旧会话回调终止新会话。去除外围页框与 Mac 信息区域卡片边框，保留原有配色与主操作卡。

Universal 构建、地址策略及 Mac 协议自检通过；两端已安装。录屏权限重新登记和持续实际连接验收待完成。此前 build 42 曾短暂传屏后失败，不代表本版已稳定。Mac 有线网络需系统提供可达网络接口，普通 USB-C 线现场未建立雷雳桥，本版不宣称普通充电线可用。

## test.5 / build 44

SCStream -3814/-3815 显示源丢失时尝试重新采集同一虚拟屏，保留传输；最多三次。主动停止共享 -3817 不自动恢复。两端已部署，尚未完成随航切换验收。复测发现首次连接确认仅等待 15 秒，会在用户允许前断开；此候选仍未通过连接稳定性验收。
