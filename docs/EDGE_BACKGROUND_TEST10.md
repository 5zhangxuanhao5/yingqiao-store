# 平板后台保留桌面修正候选 test.10

Mac 0.4.0-test.10（build 49）；HarmonyOS 0.3.16（build 49）。2026-10-21。

## test.9 真机结果

- Pro 与 MatePad Edge 已更新实测，完整版未修改。用户确认切回桌面再返回、锁屏后恢复画面与输入正常。
- 但连续锁屏记录后解锁，实际显示器编号从 32 变为 33；所以 test.9 不能视为“原屏持续保留”通过。旧的心跳失联宽限不适合系统暂停后台网络线程的情形。该失败候选及源码标签保留。

## 本次修正

- 明确区分用户主动 PARK 与媒体线路意外断开。用户已暂停的桌面不因心跳暂时缺失而自动销毁，Mac 不再为此运行 15 秒轮询。
- 原生待命仍可在后台维持或重新连接；若系统冻结它，不依赖冻结期间的 JS 定时器或媒体上传维持显示器。返回后使用新的 Surface 恢复同一 CGVirtualDisplay。
- 保留结束于明确“结束会话”、Mac 退出，或同一安装身份的新 Pad 进程出现。若系统强杀 Pad 且没有新进程连入，Mac 不能与暂时冻结可靠区分，会继续显示“桌面已保留”；可在 Mac 直接结束。
- 新协商能力为 `background-retain-v2`。后台恢复 AUTH 必须附原 PARK 会话编号并匹配已认证 Pad 进程。Mac 已结束或桌面已不存在时拒绝自动重建，平板退出恢复流程；用户仍可明确发起新会话。
- 同一恢复过程中发生媒体重试/线路接续，允许在仍持有的同一桌面上继续；结束清除该续接资格。原有主动新建连接不受影响。
- 已完成头部策略、恢复归属、结束后拒绝复活、后台任务竞争与旧端能力回退等测试。Mac 通用构建、官方 SDK 平板未签名包构建结果见日志/Actions。

本标签发布时的修正部分仍待真机验收；之后的实测结果另附验证记录。设备签名、Profile、配对数据和完整运行日志不进入公开归档。开发者触控板与 HDC 构建方式沿用已有隔离工具，官方 SDK 不改，设备分类仍为 tablet。
