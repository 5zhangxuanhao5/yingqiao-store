# 0.3.0 测试版：首次使用与附近设备

Mac和Pad均为0.3.0(21)，仅更新独立映桥测试版。个人版不变。

## 行为

- Mac首次先显示用途说明，用户继续后才交给系统申请录屏/辅助功能；不再同时主动打开系统设置。已申请后可手动点“查看设置”进入对应页。权限未给也可发现/确认设备，真正开始画面时检查必需权限。
- Pad首次显示“两端都需要安装”的说明、Mac下载链接及步骤，点击“Mac已安装”后进入首页。下载说明可再次查看。
- 首页使用扩展屏和附近Mac/Pad。没有候选时禁用开启按钮，一台直接开始，多台弹出设备选择。Pad两张卡统一高度；列表与连接过程中不提供线路选择。
- 每台Mac的已确认身份分别保存；Mac按平板随机持久ID与进程会话分别管理认证路径。启动与结束只针对所选平板；同设备重启只替换自身路径。
- 本地认证探测比较往返延迟、抖动和实测传送成本，未知或同分优先先可用线路；保留原有会话接续和手势期间防抖保护，不并行发送两路视频。
- 公开发现不是信任授权。Mac发起首次连接仅触发Pad走原有LINK，仍需在Mac点击允许。认证和媒体继续使用证书固定与令牌。

## 测试与边界

官方Harmony编译及已验收的隔离输入profile构建、Mac ARM/Intel编译和headless多Pad协调器自测、测量选路fixture均需通过。多Pad自测覆盖会话并存、选中目标、路径择优、断开隔离与同设备重启，不等于多台真机并发已测。当前只有一台Mac和Pad，首次说明/选择窗口等视觉与实际连接仍需实机验收。

本机测试USB仍为显式ORIGINAL_USB_TEST调试映射，未打包HDC；普通消费者USB、正式工具链接纳tablet禁转触摸字段、正式签名/公证及商店审核仍未完成。默认公开构建不启用调试USB。详见TRACKPAD_TEST_021.md和ORIGINAL_EXTENSION_PORT.md，不能据此称正式上架就绪。
