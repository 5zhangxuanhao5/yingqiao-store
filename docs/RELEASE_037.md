# 映桥 0.3.7 (28) 连接说明候选

本次仅更新平板连接说明和下载链接，不改动 0.3.6 的传屏、触控板和线路切换实现。Mac 配套仍为 0.3.5。

- 首页增加可展开的无线/普通 USB 使用说明，不提供手动通道选择。
- 明确普通 USB 需要系统开启 USB 共享网络，无需 USB 调试；系统未恢复共享时仍使用无线。
- 安装说明指向已云端校验的 Mac 0.3.5 下载包。
- 0.3.6 真机已验证拔线恢复无线、重新开启系统 USB 共享后自动回切、结束释放扩展屏并停止传屏。回切记录约 315 ms；不是插线到出画面的端到端延迟。
