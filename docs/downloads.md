# 下载哪个文件？

## Mac 测试版下载入口

**[打开 0.3.1 测试版 Releases 下载页 →](https://github.com/5zhangxuanhao5/yingqiao-store/releases/tag/store-v0.3.1-test.1)**

向下找到 **Assets（附件）**。下载下面的 ZIP，旁边提供对应 SHA-256 校验文件。**源码和依赖均不能直接安装。**

| 页面上的文件 | 是什么 | 普通用户该怎么做 |
| --- | --- | --- |
| `Yingqiao-Mac-Test-0.3.1.zip` | Mac 通用测试应用压缩包。 | 下载，按 [Mac 安装步骤](MAC_INSTALL.md) 解压。 |
| 与该 ZIP 对应的 SHA-256 校验文件或值 | 检查下载文件是否完整。 | 文件名必须对应上面的 ZIP。 |
| `Source code (zip)` / `Source code (tar.gz)` | GitHub 自动提供的项目源码。 | 不能双击安装；仅供开发者构建。 |
| 原生依赖、源码清单、版本说明 | 开发和恢复构建所需资料。 | 不是 Mac 安装包。 |

## 当前分发状态

- **Mac**：0.3.1 测试 ZIP 已提供。不是已完成 Developer ID 签名、公证的正式发行包；系统可能阻止打开，遇到拦截请反馈并等待合适发行包，不绕过系统检查。
- **华为平板**：仍在真机调试，尚未上架华为应用市场。设备签名测试包不代表通用商店安装包。
- **Windows**：尚未提供安装包。

测试版本可能标为 **Pre-release**，所以这里直接链接到具体版本；不要依赖 GitHub 的“Latest”入口寻找本轮测试包。
