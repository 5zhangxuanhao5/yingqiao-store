# 上架准备与实际边界

截至2026-10-18，这是独立源码开发预览，未提交审核。不能以编译成功代替商店审核或机型测试。

[华为提交指引](https://developer.huawei.com/consumer/cn/app/submit)要求准备审核指南、应用资质、基础信息等。[应用市场说明](https://developer.huawei.com/consumer/cn/appgallery/)列有隐私声明与测试分发流程。没有查到“任何联网应用或所有远控一律禁止”的可靠官方依据，因此不作这种断言。首版暂不纳入异地远控以收束产品范围；这不意味着自动免除 APP 备案、资质或隐私要求，需根据开发者身份、分发地区、分类和后台实际要求核验。

已做：独立应用标识／端口／目录；首次安装引导；主动扫码或手动粘贴本机配对；精确证书匹配；底层只允许局域网 extend；不使用 Tailscale/云中转，网络运行库为禁用适配；麦克风权限从商店变体移除、音频提供者替换为空实现，不接入个人版系统服务。原完整音频源保留作参考，未链接到商店二进制。不会自动读剪贴板，不植入共用配对令牌。

尚须完成的发布门槛：

- 公开USB配件API已找到并建立候选适配层，仍须消费级 USB 和无线接续真实打通；本仓库策略测试不能代替它。
- 不同屏幕／系统／芯片／键鼠配件的真机矩阵，最低 API24 以下的输入／解码适配或另建客户端；不能仅改 compatibleSdkVersion。
- 目前官方 SDK 不接受个人版扩展的 tablet/easyGo 字段。本预览用原版官方 schema；保留参考配置但不修改 SDK。触控板按压拖动需重新做正式配置兼容验证，未通过则不得发布。
- 为移除SDK平板可用性警告，JS触摸／鼠标桥使用公开的同步启动时间源，不读取受限制的事件时间戳；测试目录专用窗口快照接口也已移除。仍须真实验证双击、长按和拖动后才能宣布输入兼容。
- Mac 使用非公开 CGVirtualDisplay；接口有兼容风险，必须对各支持系统和三屏组合实测。Mac 不走 Mac App Store，计划 Developer ID 签名、公证、装包校验；当前本地 ad-hoc 包不能当正式公开安装器。
- 开发者实名、AGC应用标识与发布签名、所需资质、隐私政策联系人／渠道、商店截图／说明、测试账号或本地演示流程。当前 cn.edgelink.store 是占位开发标识，不代表 AGC 已登记。
- Windows 需要独立 IddCx 驱动、签名与发行安装器及真机硬件编码验证，尚无可用 Windows 扩展屏服务端。

正式测试包应先进入华为提供的邀请测试／云测试。任何未经验证的设备只列为“待测试”，不宣传“完美适配”。没有为本项目启动、替换或安装当前 Mac/Edge 上的个人版软件。

补充：公开USB配件API候选模块已用官方SDK编译，Mac IOKit控制适配arm64/x86_64对象编译通过；离线请求序列与流复用测试通过。当前主界面没有调用该模块的打开函数，所以这些结果既不代表已打通USB，更不代表商店已经接受该用法。
