已做：独立应用标识／端口／目录；首次安装引导；系统局域网发现和首次授权；精确证书匹配；底层只允许局域网 extend；不使用 Tailscale/云中转，网络运行库为禁用适配；麦克风权限从商店变体移除、音频提供者替换为空实现，不接入个人版系统服务。原完整音频源保留作参考，未链接到商店二进制。不会自动读剪贴板，不植入共用配对令牌。

尚须完成的发布门槛：

- 公开USB配件API已找到并建立候选适配层，仍须消费级 USB 和无线接续真实打通；本仓库策略测试不能代替它。
- 不同屏幕／系统／芯片／键鼠配件的真机矩阵，最低 API24 以下的输入／解码适配或另建客户端；不能仅改 compatibleSdkVersion。
- 0.3.3已用官方未修改SDK生成unsigned APP，easy_go使用common空配置；这不能代替触控板按压拖动兼容验证。个人版扩展字段仍仅作参考，不修改全局SDK。
- 为移除SDK平板可用性警告，JS触摸／鼠标桥使用公开的同步启动时间源，不读取受限制的事件时间戳；测试目录专用窗口快照接口也已移除。仍须真实验证双击、长按和拖动后才能宣布输入兼容。
- Mac 使用非公开 CGVirtualDisplay；接口有兼容风险，必须对各支持系统和三屏组合实测。Mac 仅通过 GitHub 分发，不走 Mac App Store。Developer ID 签名和公证有助于通过默认 Gatekeeper 检查，但不是提供 GitHub 下载的账号前提，也不是此处查到的华为包体检查要求。当前包未公证，须在下载页披露并提供 Apple 官方单应用确认说明；不能宣传默认双击即用或全部Mac已通过验证。
- 开发者实名、所需资质、商店截图、真实使用演示与审核联系人手机验证。cn.edgelink.store 已于2026-10-18在AGC登记为“映桥”（APP ID 6917619380035988169）；已创建正式发布证书/Profile，0.3.3正式签名APP已上传且包体合法性达标，已存入准备提交草稿，未提交审核。公开客服／隐私邮箱、隐私告知及撤回入口已加入，实际使用仍需复测。
- Windows 需要独立 IddCx 驱动、签名与发行安装器及真机硬件编码验证，尚无可用 Windows 扩展屏服务端。

正式测试包应先进入华为提供的邀请测试／云测试。任何未经验证的设备只列为“待测试”，不宣传“完美适配”。没有为本项目启动、替换或安装当前 Mac/Edge 上的个人版软件。
