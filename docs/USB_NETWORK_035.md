# 0.3.5（26）普通USB网络接续候选

此版本在consumer-usb-035候选分支开发，主分支保留0.3.4已验收的局域网修复。这里记录构建与协议检查，实际USB和拔插接续尚待验证，不是正式发行或上架通过。

## 接回现有网络通道

- Mac在本地发现启动后启动已有的用户态RNDIS/lwIP适配器，不依赖HDC、不安装内核驱动、不接入个人版系统助手。
- USB网络只通过已登记桥接连接进入127.0.0.1:49566，使用同一Mac证书、首次允许和会话令牌。普通网络中的其他连接不能借用该入口。
- 同一个USB TLS端口识别STANDBY与媒体角色，继续使用原版会话保留和独立扩展屏核心；有线/无线分别维持已认证的备用连接。
- 平板只有在已配对PATH探测确认usb-net后才配置USB网络待命，不把调试回环当消费级通道。媒体连接使用已确认的真实USB网络地址和端口。
- 根据已有测量选择器的多次样本和滞回选择通道，拖动/菜单期间延后主动切换；主动结束仍释放显示器，不走断线恢复。
- 不显示用户需要选择Wi-Fi/USB的线路菜单，不增加平板权限。保留0.3.4已通过的原厂SDK鼠标兼容修复。
