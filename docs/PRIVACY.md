## 功能与处理范围

映桥在你选择并配对的局域网电脑和平板之间提供扩展显示与操作。开发者未提供接收画面或输入的服务器，也未接入异地远控、云中转、开发者账号、广告或统计服务。本版本不接入麦克风和音频提供者，不申请麦克风权限。

为实现功能，两端在本机或已配对设备之间处理以下信息。这些信息可能包含个人信息；局域网处理并不等于完全不处理个人信息。

| 信息 | 目的、处理位置与保存方式 |
| --- | --- |
| 电脑扩展桌面画面 | Mac 系统录屏接口采集并编码后，发送给已配对平板解码显示。窗口内容可能含个人资料；请只展示愿意传给自己平板的内容。应用不提供录屏文件保存功能，也不主动上传开发者服务器。 |
| 会话内触摸、键盘、鼠标、触控板事件及光标位置 | 在已配对设备之间传递，以控制扩展桌面及支持跨屏输入；Mac 辅助功能授权具有更广泛的系统控制能力，应只授予可信软件。 |
| 局域网地址、端口与连接状态 | 用于发现和连接自己的设备。地址及部分状态会写入应用本地设置／诊断文件。 |
| 配对令牌、电脑证书及电脑私钥 | 用于身份校验和加密连接。平板保存令牌、证书及电脑地址；Mac 在本机生成并保存身份。私钥不随配对二维码传到平板，不交给开发者。二维码和令牌应视为敏感访问凭据。 |
| 屏幕／窗口尺寸、刷新率、硬件编解码能力、输入设备能力 | 在本机选择显示尺寸、帧率与输入方式；本地诊断可能包含这些能力和连接参数。不是以机型目录代替真实能力检测。 |
| 本地运行诊断 | 当前预览会记录连接结果、错误、性能计数，以及部分输入事件类型、键码、位置和时间等诊断元数据。不提供开发者自动收集入口；当前并未完成全部日志最小化审核，请勿直接公开应用数据目录。 |

## 系统能力与权限

- 平板的网络与网络状态能力用于局域网连接。系统权限名称含 INTERNET，不代表本版本提供公网远控。
- 平板的窗口光标锁定能力用于当前会话的触控板输入；不会因此宣称接管所有鸿蒙系统手势。
- 设备发现由系统 mDNS/Bonjour 与限时UDP探测在当前局域网进行；已允许电脑的最近地址也会尝试定向刷新，广播电脑名称和公开证书，不广播访问令牌或私钥。选择设备后使用对应证书建立 TLS 连接，；首次在 Mac 点击允许后，两端自动保存加密连接所需的凭据。之后使用已保存的证书校验电脑身份。按用户要求不再显示或要求核对数字；首次选择并允许采用首次信任，不能宣称已通过带外身份核对。此版本主流程不调用扫码，也不需要粘贴配对文本。
- 剪贴板仅在点击复制下载链接等复制功能时写入；不自动读取剪贴板。手动粘贴由你通过系统输入操作发起。
- Mac 录屏与辅助功能由系统控制。拒绝后无法完成相应的显示或输入功能；可在系统设置重新授权或撤销。退出映桥不会自动撤销 macOS 已授予的系统权限。
- USB 公开配件接口目前仅为未接入主流程的候选模块。此版本不会自动切换设备模式或申请配件访问；正式接入前将另行说明授权及重新枚举的影响，不要求 USB 调试。

## 保存、删除与重新配对

平板的配对、设置和诊断保存在应用沙箱；退出会话不会清除配对。系统提供的清除应用数据可删除这些本地文件，清除后需要重新配置。仅点“更换电脑”进入配对页不等于立即撤销旧电脑上的凭据。

Mac 的配对身份保存在 `~/Library/Application Support/cn.edgelink.store.mac/`，用于后续连接。需要作废时，先结束会话并退出 Mac 应用，删除该独立目录，再启动生成新身份并重新配对所有平板。请先确认路径，避免误删其他应用资料。应用当前没有一键彻底清除功能，卸载应用本体不保证删除此目录。

macOS 15 及以上请求将 TLS 身份只导入进程内存；较旧 macOS 的系统 PKCS#12 导入可能涉及系统钥匙串。旧系统行为尚待真机核验；需要清理相关身份时，可联系上述邮箱获取针对系统版本的指引，不应批量删除系统钥匙串。

诊断文件当前以本地状态文件为主，部分会被覆盖；尚未实现经验证的统一自动到期清理期限，不能承诺退出后所有诊断消失。结束会话会停止该会话的采集与发送，意外断线可能短暂保留扩展屏以等待接续；这不等同于持续录制或保存视频文件。

## 第三方与主动联系

mDNS/Bonjour 由设备系统的局域网服务发现能力提供，不使用开发者云服务。OpenSSL、Opus 等依赖及许可证见仓库 THIRD_PARTY_NOTICES；存在库文件不表示启用云服务或录音。

只有你自行打开电脑端下载地址时，才会访问 GitHub；该网站可能处理访问地址、Cookie 或登录资料，适用其自身隐私政策及网络条件。应用不自动把配对内容或画面上传 GitHub。公开 Issue 不是私密客服渠道，不要提交密码、令牌、二维码、证书私钥、录屏或未脱敏日志。

你主动发邮件时，开发者会收到你提供的地址和问题内容，邮件服务商也会处理邮件。只提供解决问题必要的信息；不要发送账户密码或完整配对资料。联系邮箱使用 Gmail，邮件传输与处理受对应服务规则及所在地影响，不能保证仅在中国大陆处理。开发者不以此建立广告画像或出售资料。
