# 映桥 0.3.2（23）· 名称与发布准备

商店分支名称由“映桥测试版”改为“映桥”，Mac 与平板同步。应用标识、配对数据和原有扩展屏功能保持不变。个人完整版本另名“映桥完整版”，源码及归档仍在独立私有仓库。

## 验证与状态

- Mac Intel/Apple Silicon 通用构建与平板 HAP 构建通过。两端已保留数据安装成功；Mac 应用身份、稳定本机签名和新名称已核对。
- 0.3.1 的附近设备发现与连接已由用户实机确认；本次没有修改传输/输入核心，改名后完整会话尚待实机复测。
- 华为后台草稿已保存，未提交审核、未上架。
- 当前可装平板包使用两台设备限定的 debug Profile，不是正式发行签名，不随公开 Release 上传。
- 当前触控板按压兼容使用工程私有 SDK schema 配置，正式工具链支持情况仍待解决。
- 经过验收的 USB 测试通道依赖 HDC 调试环境。普通消费者 USB 与无缝切换尚不能作为发布承诺。
- Mac 测试包是本机稳定签名，不是 Developer ID 公证包。
- 商店真实截图、内容分级、隐私标签、联系人短信验证与分类/备案要求仍待完成。

下载附件中的 Mac ZIP 是受控测试包；设备覆盖范围和正式分发状态以本说明为准。源码、清单和依赖附件用于恢复开发，不是面向消费者的完整安装流程。
