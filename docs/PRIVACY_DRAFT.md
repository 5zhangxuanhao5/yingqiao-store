# 隐私说明草案（提交前需补全开发者主体与联系方式）

本开发预览仅用于本人配对电脑和平板之间的局域网扩展显示。需要电脑画面和在映桥窗口内产生的输入事件才能提供显示及操作；配对信息含访问凭据，存储在各自应用目录，不上传开发者服务器。系统录屏、辅助功能由你在电脑授权，缺少时会提示并打开系统页面。扫码只在点击时打开系统扫码界面；剪贴板只在点击复制链接或配对信息时写入，不自动读取。

不提供异地远控，不内置广告、统计 SDK、账号服务、云中转或录音；本变体没有麦克风权限和音频提供者。运行诊断只保存在本机，当前原型仍需完成日志最小化及保留期限检查，正式隐私政策需准确覆盖最终版本。电脑 TLS 身份在首次准备时本地生成；较旧 macOS 的系统 PKCS#12 导入可能使用系统钥匙串，需在真实系统验证并准确披露。

只在用户点击复制链接后将电脑端下载地址写到剪贴板。自行访问 GitHub 时适用 GitHub 自身的隐私政策及网络可用性。配对凭据不可发送到公开 Issue、截图或工单。

草案缺少实际运营主体、联系渠道、删除数据入口及保留期限；不是可直接提交的正式法律文本。

USB候选接口已经编译验证但未接入连接流程。后续启用时需针对所连接配件的系统授权，不依赖USB调试；若切换配件模式会重新枚举或影响传文件，必须先明确告知。此预览不会自动发起这些操作。
