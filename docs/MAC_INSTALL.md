# 在电脑安装映桥

当前是独立开发预览，尚无通过签名、公证和多机型验证的正式安装包；请勿将源码附件误认为可直接安装的产品。正式版准备好后，会在本仓库 Releases 提供下载与 SHA-256。

正式引导流程：

1. 在电脑浏览器打开 https://github.com/He-He-He-He-He-He/yingqiao-store ，进入 Releases。
2. 阅读支持系统和已验证机型。Mac 正式包计划为 Intel 与 Apple Silicon 通用版，最低系统仍以最终实测结果为准。
3. 下载正式签名／公证的 DMG，打开后将“映桥”拖入“应用程序”，再启动。不要关闭 Gatekeeper，不运行绕过安全检查的命令。
4. 点击准备扩展屏。缺少录屏或键鼠控制权限时，应用直接打开对应系统页面；系统要求的本人授权不能绕过。
5. 平板首次打开选择“是，已安装”，扫描电脑二维码。无需手填 IP、证书、分辨率或码率；无法扫码时提供完整配对信息的粘贴备用方式。
6. 点击开启扩展屏。结束后释放屏幕与采集；有线／无线接续仅在正式版本完成相应验收后开放。

Windows 正式包尚未实现，不提供虚假下载按钮。现阶段不要把当前个人版或其配对数据发给他人。
