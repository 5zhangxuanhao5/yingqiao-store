# 在 Mac 安装映桥

## 1. 打开下载页

**[点此进入 Mac 0.3.5 测试版下载页](https://github.com/5zhangxuanhao5/yingqiao-store/releases/tag/store-v0.3.6-tested-unplug.1)**

这个链接可以复制到 Mac 的 Safari、Chrome 或 Edge 地址栏打开。无需安装 Git 或开发工具。

本轮 Mac 测试包文件名是 **`Yingqiao-Mac-0.3.5.zip`**。在页面往下找 **Assets（附件）**，点击这个文件下载。如果尚未看到它，或页面暂未发布，请等附件准备完成；不要下载源码来代替安装包。文件区别见 [下载文件对照](downloads.md)。

这是一份尚未完成 Developer ID 签名与 Apple 公证的测试包，不是已公证发行版。Mac 客户端通过 GitHub 分发，不上架 Mac App Store；提供 GitHub 下载不以开通 Apple 开发者账号为前提。没有 Developer ID 和公证会影响 macOS 的首次打开体验，系统可能阻止直接启动，不能承诺下载后双击即用。

如果提示无法验证开发者或无法检查恶意软件，请先确认下载地址确为本仓库、文件名与本版本一致，并核对下方 SHA-256。只有你本人确定信任来源后，才可自行参照 [Apple 官方“在 Mac 上安全地打开 App”](https://support.apple.com/zh-cn/102445) 的单个应用确认流程操作；该页面说明了“系统设置 → 隐私与安全性 → 仍要打开”。这由使用者自己判断和确认，映桥不会代为关闭系统保护、安装根证书或运行取消检查的脚本。若提示“将损坏你的电脑”、签名被撤销、文件损坏或哈希不符，请停止并反馈；组织管理的 Mac 也可能不允许此类应用。

## 2. 解压并放入“应用程序”

当上述 ZIP 已出现在附件列表中时：

1. 等浏览器下载完成，打开 Mac 的 **访达 → 下载**。
2. 双击 `Yingqiao-Mac-0.3.5.zip` 解压。
3. 找到解压后的 **“映桥.app”**，把它拖到访达左侧的 **“应用程序”**。
4. 从 **“应用程序”** 中双击 **“映桥”** 启动。

个人版现名“映桥完整版”，与本应用使用不同的应用标识和数据目录。更新旧“映桥测试版”时，请退出旧应用，再安装本版本“映桥”；不要覆盖“映桥完整版”。

本轮提供 Intel 与 Apple Silicon 通用包，不需要自己选 M 系列或 Intel 文件。最低构建目标为 macOS 13，实际支持范围仍需逐系统、逐设备测试；不承诺所有型号均可用。

## 3. 阅读用途说明，再授权

首次启动先出现映桥自己的用途说明。点击继续后，再由 macOS 请求对应权限，不会提前把系统设置打开。

| 权限 | 用途 |
| --- | --- |
| 本地网络 | 寻找并连接你选择的附近设备。 |
| 录屏 | 把扩展桌面的画面显示在平板上。 |
| 辅助功能 | 接收平板上的键盘、鼠标、触控板和触摸操作。 |

设备发现不以录屏和辅助功能批准为前提，但开始扩展屏前需要这两项权限均有效。若系统授权尚未完成，首页会显示相应状态；点击已经请求过的权限旁的 **“查看设置”**，可进入对应系统页面。触控 ID、系统密码与权限确认由本人完成，不需要发给任何人。

## 4. 连接平板

1. 先让 Mac 与平板连接同一 Wi‑Fi 或同一部手机的热点，并在两端打开“映桥”。
2. 平板首次引导询问电脑是否已安装时，选择 **“已安装”**。
3. 在平板的 **“附近的 Mac”** 选择你的电脑；也可以在 Mac 的 **“附近的 Pad”** 选择平板。
4. 首次连接时，Mac 会显示 **“允许这台平板连接？”**。确认是你刚刚操作的平板后，点 **“允许连接”**。
5. 点击 **“开启扩展屏”**。发现多台设备时选择本次使用的设备；只有一台时直接连接。无需填 IP、证书、分辨率、码率或匹配码。

如果没有发现设备，请检查两端应用是否打开、是否在同一个局域网。校园或公司网络可能限制设备互相访问，可用同一手机热点对照检查。普通USB网络已在当前MatePad Edge验证，不需要开发者选项或HDC转发。请用支持数据传输的线连接Mac与平板，在平板系统设置搜索并开启“USB共享网络”，然后回到映桥；应用会在后台认证和比较可用线路，不需要手选USB或无线。

当前实测：拔线后可以恢复已就绪的同一局域网线路并保留扩展桌面；重新插线时系统没有自动保留USB共享模式，需重新开启该开关，应用才能重新发现普通USB网络。暂不能承诺任意设备只插线即用，也不能把画面仍正常误认为已切回有线。如果系统没有此开关，先保持无线，不要求安装系统驱动或关闭安全保护。

## 5. 结束会话

在映桥菜单中点 **“结束会话”**。Mac 会停止本次画面采集、编码和传输，继续保留设备发现，便于下次连接。
