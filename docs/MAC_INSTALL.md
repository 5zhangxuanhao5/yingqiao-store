# 在 Mac 安装映桥测试版

## 1. 打开下载页

**[点此进入 Mac 0.3.1 测试版下载页](https://github.com/5zhangxuanhao5/yingqiao-store/releases/tag/store-v0.3.1-test.1)**

这个链接可以复制到 Mac 的 Safari、Chrome 或 Edge 地址栏打开。无需安装 Git 或开发工具。

本轮 Mac 测试包文件名是 **`Yingqiao-Mac-Test-0.3.1.zip`**。在页面往下找 **Assets（附件）**，点击这个文件下载。如果尚未看到它，或页面暂未发布，请等附件准备完成；不要下载源码来代替安装包。文件区别见 [下载文件对照](downloads.md)。

这是一份尚未完成正式 Developer ID 签名与 Apple 公证的测试包，主要用于受控调试。它不是已公证的正式发行版，其他 Mac 可能无法直接打开。系统如果阻止安装或启动，请停止并反馈提示，等待可正常验证的发行包；不要关闭 Gatekeeper 或运行绕过安全检查的命令。

## 2. 解压并放入“应用程序”

当上述 ZIP 已出现在附件列表中时：

1. 等浏览器下载完成，打开 Mac 的 **访达 → 下载**。
2. 双击 `Yingqiao-Mac-Test-0.3.1.zip` 解压。
3. 找到解压后的 **“映桥测试版.app”**，把它拖到访达左侧的 **“应用程序”**。
4. 从 **“应用程序”** 中双击 **“映桥测试版”** 启动。

已有个人版“映桥”的用户请保留个人版；测试版使用单独的名称和应用标识。更新已有测试版时，先正常退出旧的“映桥测试版”，再替换同名测试应用。

本轮提供 Intel 与 Apple Silicon 通用包，不需要自己选 M 系列或 Intel 文件。最低构建目标为 macOS 13，实际支持范围仍需逐系统、逐设备测试；不承诺所有型号均可用。

## 3. 阅读用途说明，再授权

首次启动先出现映桥自己的用途说明。点击继续后，再由 macOS 请求对应权限，不会提前把系统设置打开。

| 权限 | 用途 |
| --- | --- |
| 本地网络 | 寻找并连接你选择的附近设备。 |
| 录屏 | 把扩展桌面的画面显示在平板上。 |
| 辅助功能 | 接收平板上的键盘、鼠标、触控板和触摸操作。 |

设备发现不以录屏和辅助功能批准为前提，但开始扩展屏前需要这两项权限均有效。若系统授权尚未完成，首页会显示相应状态；点击已经请求过的权限旁的 **“查看设置”**，可进入对应系统页面。触控 ID、系统密码与权限确认由本人完成，不需要发给任何人。

## 4. 连接平板

1. 先让 Mac 与平板连接同一 Wi‑Fi 或同一部手机的热点，并在两端打开“映桥测试版”。
2. 平板首次引导询问电脑是否已安装时，选择 **“已安装”**。
3. 在平板的 **“附近的 Mac”** 选择你的电脑；也可以在 Mac 的 **“附近的 Pad”** 选择平板。
4. 首次连接时，Mac 会显示 **“允许这台平板连接？”**。确认是你刚刚操作的平板后，点 **“允许连接”**。
5. 点击 **“开启扩展屏”**。发现多台设备时选择本次使用的设备；只有一台时直接连接。无需填 IP、证书、分辨率、码率或匹配码。

如果没有发现设备，请检查两端应用是否打开、是否在同一个局域网。校园或公司网络可能限制设备互相访问，可用同一手机热点对照检查。当前普通用户请先使用局域网测试；开发用 USB 通道需要单独测试环境，不代表插上任意数据线即可工作。

## 5. 结束会话

在映桥菜单中点 **“结束会话”**。Mac 会停止本次画面采集、编码和传输，继续保留设备发现，便于下次连接。

## 校验下载文件（可选）

版本附件或说明会提供与 `Yingqiao-Mac-Test-0.3.1.zip` 对应的 SHA-256 值。请核对文件名后比较；源码清单中的哈希不能代替安装包哈希。若本轮尚无对应校验值，说明交付核验还没有完成。

当前没有 Windows 安装包，也尚未上架华为应用市场。请以指定测试版本页面的真实附件和验证说明为准。
