# 0.2.2 Mac 会话连接清理修复

Edge 0.2.1恢复原版触控板配置后尝试连接，报告TLS unexpected EOF。两条备用通道仍ready；检查发现stopSession取消onClose后没有从peers移除controller/viewer，旧条目累积会触及8个连接上限，导致握手前被拒绝。

本修复在关闭旧控制/视频连接前明确移除其登记。保持8连接上限和认证、传输、输入、权限不变。Mac 0.2.2(20)配合Edge 0.2.1(19)，个人版不变。0.2.1的隔离输入配置构建及正式商店兼容限制继续适用。安装后连接及拖动仍待设备验收；源码分析不替代反复连接压力验证。
