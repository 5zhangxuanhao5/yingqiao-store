# 映桥 0.3.10 · USB 发现稳定性候选

仅更新公版平板端，Mac 沿用 0.3.5，完整版不变。

- 单个旧无线目标探测失败不再重启整个发现服务。仅整轮发送均失败且近期没有收到发现应答时，恢复 UDP 通道。
- 无线服务消失时，保留近期通过 USB/UDP 发现应答确认的设备。
- 恢复 UDP 时保留其他设备发现状态。

官方 SDK 构建检查及设备验收仍分别记录。用户确认 Mac 能通过普通 USB 发起传屏，但平板在关闭 Wi-Fi 后设备列表闪烁；本候选修复该路径，尚待实测。

按压拖动跨屏仍未解决；本版本不宣称输入修复，也不提交华为邀请测试。普通 USB 仍需开启系统 USB 共享网络。
