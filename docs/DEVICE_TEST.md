# 映桥测试版真机调试

用户于2026-10-18明确要求暂停上架，并在当前Mac和MatePad安装本独立工程调试。

- 名称均为“映桥测试版”，平板bundle为cn.edgelink.store，Mac为cn.edgelink.store.mac；不覆盖原个人版的cn.edgelink.lab/cn.edgelink.maclab。
- Mac安装路径为/Applications/映桥测试版.app，使用独立配置目录和专用端口49563/49564。原个人版与iPad随航的设置不主动改变。
- 当前先测局域网扩展屏；USB调试仅负责安装、读取诊断和用户授权的本机配对传送。普通消费者USB通道尚未接入，不把调试线当作产品USB能力。
- 初次需在Mac为测试版单独授予录屏和辅助功能；不复用个人版的系统授权，不安装合盖、麦克风或公网远控服务。
- 平板签名仅在Git仓库外的本机测试副本配置；设备Profile、签名证书、密码和真实配对信息均不得公开。
- 默认构建是本机预览签名，非公证发行包。真机安装及结果另记部署记录，编译本身不代表流畅度或输入已经通过。
