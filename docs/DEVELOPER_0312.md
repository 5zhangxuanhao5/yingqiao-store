# 映桥 0.3.12 开发者版

本分支只供 GitHub 开发分发，不提交华为应用市场；不会替换已提交审核的 0.3.11，也不涉及映桥完整版。Mac 配套保持已安装的 0.3.5。

以用户已确认跨屏按压拖动正常的 0.3.2 为基础。保留其鼠标、触屏和媒体实现；开发构建必须显式运行 `tools/prepare-original-tablet-test.py --device-test-only`，保留纯 tablet 和 `mouse2TouchEventMode=disabled`。配置仅写入独立构建目录；不修改系统安装的 SDK。默认原厂 SDK 构建不会自动启用这项实验配置，不能把二者称为同一安装包。

## 本轮变化

- 刷新时清除展示设备和选择状态。按钮仅依据当前可达设备，不由历史配对或旧连接状态点亮。
- 搜索到的设备先通过短 TCP 可达性检查；每 3 秒复核，超时 1.2 秒。全部线路不可达时从当前列表移除；后台可重试最近观察到的候选，但不展示离线设备。
- 同一设备的无线和 USB 网络地址合并；一条线路失败不会删除另一条仍可连接的线路。保留有线/无线发现与已有自动线路选择逻辑。
- USB 网络依赖系统 USB 共享网络模式；不宣称只插线即用。未修改 Mac，不自动开启系统共享或开发者设置。
- 移除平板首页下载与安装说明、复制链接入口及首次安装下载引导。

## 验证边界

模拟检查覆盖：不可达设备不显示、上线出现、离线移除、仅 USB 网络、无线失败但 USB 仍可用、停止后的异步回调丢弃及短连接释放。鼠标/触屏处理函数与已验收 0.3.2 字节一致。当前候选真实安装、拖动和 USB 独立发现结果以设备收据为准，不用模拟代替真机。

公开归档包含源码、依赖、Mac 配套包与恢复方法；带本人设备 Profile 的调试 HAP 留在本机，不进入公开 GitHub。构建者须使用自己的调试签名与设备登记。
