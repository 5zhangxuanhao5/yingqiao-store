# 映桥 · 应用商店版开发预览

**开发中，暂不上架。当前版本以“映桥测试版”名称安装真机调试，独立于个人版，不提供正式分发安装器。**

目标：让不同华为平板成为电脑的独立扩展屏，以有线／无线自动接续和自动设备适配为核心。电脑端最终由本公开仓库分发，平板端最终走华为应用市场。当前不提供异地远控。

已实现的开发基础：

- 独立标识与本机配置目录，不修改已安装个人版。
- 平板自动发现同一局域网的 Mac，点选后首次由 Mac 允许；自动保存凭据，之后直接连接。下载链接与安装步骤放在辅助说明中，不要求扫码、复制配对信息或填 IP。
- 按实际屏幕比例、硬件解码能力选择尺寸／编码／帧率；不锁定 MatePad Edge。
- Mac 最低构建目标 macOS13，Intel与Apple Silicon通用二进制编译通过。仅真实系统测试后才列为支持。
- 原生 TLS 精确配对证书校验、每会话AES-GCM视频密钥；底层限制局域网扩展用途。
- 已加入普通权限 RNDIS 用户态 USB 网络桥，0.1.13在当前设备实机获得地址并通过USB传屏，不依赖HDC。拔线可恢复无线且窗口保留；切换停顿优化与插回USB仍待验收。
- 异常断开保留显示器的10秒接续基础、显式结束释放；线路选择和屏幕比例策略测试通过。

**没有完成的核心：消费级USB通道与实际无缝切换、真实多机型矩阵、正式签名／公证及上架审核。策略测试不能替代它们。** 当前平板会话支持已验证设备的局域网与RNDIS USB实验通道，未宣称任意机型下载即可完美工作。
